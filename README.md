# 🛡️ NSSF Security Scan - Telegram Bot

Bot Telegram ស្កេនសារបោកប្រាស់ (ខ្មែរ/អង់គ្លេស) តំណភ្ជាប់ និងឯកសារ តាមរយៈ **VirusTotal v3** ព្រមាន Dashboard សម្រាប់អ្នកគ្រប់គ្រង។

## គោលការណ៍សំខាន់ៗ
- **មិនមានលទ្ធផលក្លែងក្លាយ។** បើ VirusTotal មិនអាចប្រើបាន ឬឯកសារធំជាង 20MB លទ្ធផលគឺ `UNKNOWN` (មិនទាន់ស្កេន) មិនមែន "SAFE" ទេ។ ឯកសារ/URL ដែល VirusTotal មិនធ្លាប់ឃើញ ត្រូវបាន upload ហើយរង់ចាំលទ្ធផល។
- **ឯកជនភាព។** លំនាំដើមរក្សាតែ hash របស់សារ (មិនរក្សាអត្ថបទ) ហើយលុបទិន្នន័យស្វ័យប្រវត្តិបន្ទាប់ពី `RETENTION_DAYS`។
- **សុវត្ថិភាព API។** គ្រប់ `/api/*` ត្រូវការ `ADMIN_TOKEN`; webhook ផ្ទៀងផ្ទាត់ `WEBHOOK_SECRET`។

## ដំឡើងក្នុងម៉ាស៊ីន (Polling)
```bash
pip install -r requirements.txt
cp .env.example .env      # បំពេញតម្លៃ
python run_bot.py         # bot (restart ស្វ័យប្រវត្តិ)
python server.py          # dashboard នៅ http://localhost:8000
```
> ប្រើ **Polling ឬ Webhook** តែមួយប៉ុណ្ណោះ មិនអាចប្រើទាំងពីរក្នុងពេលតែមួយបានទេ។

## Deploy លើ Vercel + Supabase (Webhook)
1. Supabase SQL Editor៖
```sql
CREATE TABLE scan_logs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    chat_id TEXT, chat_type TEXT, sender_id TEXT,
    user_name TEXT DEFAULT '', ip_address TEXT DEFAULT '',
    scan_type TEXT, input_summary TEXT, risk_level TEXT, risk_score INT,
    threat_details JSONB, virustotal_details JSONB
);
-- បើក RLS ដើម្បីកុំឱ្យ anon key អានបាន; service-role key ឆ្លងកាត់ RLS
ALTER TABLE scan_logs ENABLE ROW LEVEL SECURITY;
```
   បើអ្នកមាន table ចាស់ សូមបន្ថែម column៖ `ALTER TABLE scan_logs ADD COLUMN user_name TEXT DEFAULT '', ADD COLUMN ip_address TEXT DEFAULT '';`
2. Vercel Environment Variables៖ `TELEGRAM_BOT_TOKEN`, `VIRUSTOTAL_API_KEY`, `SUPABASE_URL`, **`SUPABASE_SERVICE_KEY`** (មិនមែន anon), `ADMIN_TOKEN`, `WEBHOOK_SECRET`, `PUBLIC_BASE_URL`។
3. Deploy ហើយចុះឈ្មោះ webhook មួយដង៖
```bash
curl -X POST https://YOUR_APP.vercel.app/api/set_webhook -H "Authorization: Bearer $ADMIN_TOKEN"
```

## ការកំណត់ (Environment)
មើល [.env.example](.env.example)។ ចំណុចសំខាន់៖ `STORE_MESSAGE_TEXT` (`hash`/`full`), `RETENTION_DAYS`, `ADMIN_TELEGRAM_IDS` (អ្នកប្រើ `/status` បាន), `USER_RATE_LIMIT_PER_MIN`, `VT_REQUESTS_PER_MIN` (4 សម្រាប់គណនីឥតគិតថ្លៃ)។

> **LLM (ជម្រើស)៖** បើដាក់ `GEMINI_API_KEY` ឬ `OPENAI_API_KEY` សារដែលពិន្ទុនៅកណ្ដាលនឹងត្រូវផ្ញើទៅអ្នកផ្តល់សេវានោះដើម្បីសុំយោបល់ទីពីរ។ សូមបញ្ជាក់ក្នុងគោលការណ៍ឯកជនភាពរបស់អ្នក។
